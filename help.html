    Using these docs

    How the documentation is organised, and how to find what you need.

    Finding your way

    The bar at the top of every page links to the main sections. The underlined link shows which section you are in.

    The search box jumps straight to a page. Start typing a keyword, algorithm or command, then pick a result, or press Enter to open the first one.

    The line under the bar shows where you are, and the On this page links jump to each part of a long page.

    Kinds of page

    Each page and search result has a coloured label showing what kind of thing it describes.

    • SectionOne page each for Language, Catalogue, Errors and Commands. Each one introduces its topic and lists the pages inside it. Use the filter buttons above a table to show one group at a time.
    • KeywordOne page per QuLang keyword, with its syntax, a description, a summary of its parts, examples, related errors and links to related pages.
    • CommandThe qu command-line tool and each of its commands.
    • ErrorOne page per error or warning, explaining what causes it and how to fix it.
    • PageGeneral pages, such as the overview, the A–Z index and this help page.

    Catalogue pages, one per algorithm family and per algorithm, will be generated from the catalogue file, so they always match what QuLang actually uses.
